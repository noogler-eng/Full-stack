Native

Android & iOS (Native)

Kotlin/Jetpack Compose + Swift/SwiftUI. Two separate codebases, each compiled straight to platform machine code with full OS access.

 React Native

React Native

JavaScript/TypeScript + React. One codebase, a JS engine, and a bridge (or the new JSI/Fabric architecture) into real native UI components.

 Flutter

Flutter

Dart, compiled ahead-of-time. One codebase that draws every pixel itself via its own engine and rendering layer — it doesn't use native UI widgets at all.

02The one-paragraph mental model

Native (Android/iOS)

  • Your code is the OS's own UI framework — no translation layer.
  • Maximum performance & platform capability, minimum shared code.

React Native

  • Your JS describes a UI tree; RN turns that tree into real native views.
  • You share logic across platforms, but the visible widgets are still native.
Flutter, in one line Flutter doesn't ask the OS to draw a button — it draws the button itself, pixel by pixel, using its own graphics engine (Skia/Impeller), and only touches native OS APIs for things like camera, GPS, or notifications.
