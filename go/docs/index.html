package main

import "fmt"

func main() {
	name := "Gopher"
	greeting := "Hello, " + name
	fmt.Println(greeting)
}
  1. Every Go file starts by naming its package. main is special: it means “this builds into a program you can run”.
  2. We import the standard-library package fmt (short for “format”) so we can print.
  3. Execution begins at func main(). No arguments, no return value.
  4. := declares a variable and lets Go infer its type — here a string.
  5. + joins strings into a brand-new string.
  6. fmt.Println writes the value plus a newline to standard output. Done! Click through any walkthrough like this one.
